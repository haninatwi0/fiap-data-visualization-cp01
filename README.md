📊 Visualização de Dados — Checkpoint 01

Projeto acadêmico desenvolvido na disciplina de Data Science and Analytics da FIAP.

O objetivo da atividade foi utilizar técnicas de visualização de dados para investigar um dataset, formular perguntas e apresentar os resultados por meio de diferentes tipos de gráficos.

🛠️ Tecnologias
Python
Jupyter Notebook
Pandas
Plotly / Seaborn
📌 Conteúdo

O notebook apresenta:

análise e manipulação dos dados;
perguntas investigativas;
criação de diferentes visualizações;
personalização dos gráficos;
comparação entre gráficos padrão e customizados;
interpretação dos resultados.
